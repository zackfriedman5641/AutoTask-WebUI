This a WebView2 based application designed to run Autotask as its own dedicated window.
The WebView2 folders and DLLs in this directory are required for the application to run correctly.

You must download this entire directory and launch the WebUI.exe application within it.

To created a desktop shortcut, you just need to set the target to WebUI.exe wherever it lives.

The installer script will copy the files to C:\Program Files and place a desktop shortcut in $env:PUBLIC\Desktop.
